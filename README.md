# Bonito Escudo

Mini juego en **Phaser 3**: un conejo en el centro con escudo; balas aparecen desde arriba, abajo, izquierda o derecha. **Toca la pantalla** para orientar al personaje hacia ese lado y bloquear la bala si coincide la dirección.

## Archivos

- `index.html` — página y HUD
- `styles.css` — layout responsive
- `main.js` — lógica del juego

Phaser se carga desde CDN (jsdelivr).

## Ejecutar en local

Sirve la carpeta con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```

## Despliegue

Compatible con GitHub Pages o Vercel como sitio estático.
